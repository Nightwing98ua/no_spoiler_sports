# Backend для сайту "без спойлерів"

API-сервер на Flask, який віддає список матчів з оцінкою за днями.

## Джерела даних

- **NHL** — офіційне публічне API, без ключа.
- **Футбол** — неофіційне, але стабільне й багато років використовуване
  публічне API ESPN. Теж без ключа й реєстрації. Покриває АПЛ, Ла Лігу,
  Серію А, Бундеслігу, Лігу 1 та Лігу чемпіонів (список легко розширити
  у `football_provider.py`, словник `LEAGUES`).

Оцінка футбольних матчів рахується спрощено — за голами й різницею
рахунку (без детальної статистики: удари/xG ESPN тут не віддає).

## Встановлення

```
pip install -r requirements.txt
```

Ключі не потрібні — ні для футболу, ні для хокею.

## Запуск

```
python app.py
```

## Використання

```
GET /api/matches?sport=football&date=2026-09-10
GET /api/matches?sport=hockey&date=2026-09-10
```

Дані кешуються на 1 годину.
